Screen glass: direct-framebuffer preservation

This local fixture compares the actual GPU output of a direct scene render with the glass compositor. The scene includes untonemapped color artwork, a white reference patch, a lit PBR object and transparent background. It does not load or change a tarot reading.

Eight cases reuse the compositor across light/dark, DPR 1/2 and two canvas sizes. This checks the current browser/GPU, not cross-device visual acceptance.
